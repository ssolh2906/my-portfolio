## Stack pinning — read before writing code

Next.js **16.3** (App Router) + React **19.2** + Tailwind **v4** + framer-motion 12. All four differ from older conventions that may be in training data:

- `AGENTS.md` (auto-regenerated by `next dev`, so don't fight the diff — commit it with your work) instructs reading `node_modules/next/dist/docs/` before writing Next code. Do that for anything non-trivial.
- Layout/page props come from Next-generated global types: `RootLayout({ children }: LayoutProps<"/">)`, not a hand-written interface. See `src/app/layout.tsx`.
- **Tailwind v4 has no `tailwind.config.js`.** Theme tokens live in `@theme inline` inside `src/app/globals.css`; PostCSS wiring is `@tailwindcss/postcss` in `postcss.config.mjs`. Utility syntax changed in v4 (e.g. `bg-linear-*`, not `bg-gradient-*`).
- Path alias `@/*` → `./src/*`.
- Verify a library is in `package.json` before importing it. There is no chart library installed yet — picking one is an open decision (see below).

## Architecture

Single-page site. `src/app/page.tsx` composes section components in order; there is no routing beyond `/`. Sections are added one at a time in this build order:

**Hero → About → Projects (charts) → Skills/Experience → Contact.** Hero and About exist; the rest do not.

Each section lives in `src/components/<section>/` and follows the same shape:

- `"use client"` — sections are client components because they animate.
- Module-scope `container` / `item` framer-motion variants (`staggerChildren` on the parent, `opacity`/`y` on children, `ease: [0.16, 1, 0.3, 1] as const`).
- `useReducedMotion()` guards every animation — pass `initial={reduceMotion ? "show" : "hidden"}` and zero out parallax transforms rather than skipping the guard.
- `id` matching the `#anchor` in `Nav`'s `NAV_LINKS`.

**The dark→light seam is load-bearing.** Hero is a full-viewport dark section (`#050912`) with a video layer, legibility scrim, radial glow, and a circuit-grid overlay stacked as absolute siblings. About then paints its own top-edge gradient from `#050912` into the light body (`#f6f8fb`) so the two sections read as one continuous page. Any new section boundary near the hero has to preserve that continuity, and new sections below About stay on the light theme.

Hero's `<video>` currently has no `<source>` — it renders `poster="/hero-poster.png"` until the ambient bio/DNA loop is ready.

## Design direction

Constraints, not final values — let the design skill choose specifics.

- Dark atmospheric hero → light, readable body (data legibility wins below the fold).
- Accent: **blue** family, teal acceptable as secondary. **No purple.**
- Signature effect: liquid glass / frosted translucent panels (see `Nav` and the About stat strip — `backdrop-blur` + `bg-white/x` + inset-highlight shadow).
- Asymmetric, grid-based, generous whitespace. No centered-hero cliché.
- Keep static-export friendly; no SSR is needed.

### Data-viz rules

This portfolio is graph-heavy. Charts live on the light theme, readability over decoration. Gradients are for the frame (hero, cards), never for chart data. Axes and legends stay WCAG AA contrast.

## The sc-covid dataset (Projects section)

`data/sc-export/` holds the exported artifacts of a separate analysis repo, [ssolh2906/sc-covid](https://github.com/ssolh2906/sc-covid) — 100K blood single-cell RNA-seq cells (50K COVID-19 / 50K healthy) from CELLxGENE Census, visualized via scVI embedding → UMAP. It is **untracked in git** and was produced elsewhere; treat it as read-only input, do not regenerate or "fix" its numbers.

- `umap_points.json` — ~24K downsampled cells (2.6 MB), keys deliberately short: `x`, `y`, `ct` (cell type, 20 major + `Other`), `d` (`"COVID-19"` | `"normal"`), `cd14`/`mki67`/`ighg1` (log1p expression). Rows are pre-shuffled so neither condition paints over the other — preserve that order when rendering.
- `celltype_proportions.json` — per-condition proportions + fold change, computed on the full 100K (not the downsample). This is the source for the interactive bar chart.
- `summary.json` — cohort metadata plus `markers[*].vmax_p99`, which should be used as the color-scale ceiling so interactive marker plots match the original figures.
- `figures/` — the six original matplotlib PNGs, as fallback/reference.

`docs/sc-covid-research.md` (Korean) is the authoritative record of methodology, exact numbers, and interpretation; `docs/sc-covid-export-instructions.md` documents the export contract these JSONs satisfy. Read the research note before building charts.

Four caveats from that note are meant to be surfaced in the UI, not buried: uneven annotation resolution between datasets can inflate fold changes for broad categories; there is no severity metadata; it is a cross-sectional snapshot, not a time series; and the three marker genes were hand-picked from known biology rather than derived from differential expression.
